# SCHEMA — นิยามฟิลด์และระบบความเชื่อมั่น

ไฟล์รายคลองทุกไฟล์มี YAML frontmatter ชุดเดียวกัน อ่านด้วยโปรแกรม/AI ได้โดยตรง เนื้อหาเป็นภาษาไทย โดยมีชื่อคลองภาษาอังกฤษกำกับ

## ฟิลด์ใน frontmatter

| ฟิลด์ | ค่าที่เป็นไปได้ | ความหมาย |
|---|---|---|
| `id` | slug ภาษาอังกฤษ | ชื่อไฟล์/ไอดีอ้างอิง เช่น `khlong-saen-saep` |
| `name_th` / `name_en` | ข้อความ | ชื่อทางการ |
| `aliases` | รายการ | ชื่อเรียกอื่น ชื่อเก่า สะกดแบบอื่น (รวมชื่อที่สับสนบ่อย) |
| `bank` | `east` \| `west` \| `north` \| `offsite` | ฝั่งเจ้าพระยาที่คลองอยู่ (`offsite` = อยู่ต่างจังหวัดแต่เชื่อมเครือข่าย เช่น ระพีพัฒน์) |
| `endpoints` | รายการ `[จาก, ถึง]` | จุดเชื่อมต่อปลายทั้งสองข้าง (ตัวพิมพ์ไทย ตามแหล่งอ้างอิง) |
| `coordinates` | `[lat, lng]` × 2 | ปลายคลองโดยประมาณจาก OSM (คลาดเคลื่อน 50–200 ม.) — `null` ถ้าไม่มีข้อมูล |
| `length_km` | ตัวเลข | ความยาวตามแหล่งอ้างอิง (แหล่งอาจต่างกัน — ใส่ช่วงในเนื้อหา) |
| `built` | ข้อความ | ปี/รัชกาลที่ขุด และวัตถุประสงค์เดิม |
| `flow_type` | ดูตารางด้านล่าง | กลไกการไหลหลักของคลอง |
| `drainage_outlets` | รายการ | เมื่อระบบระบายน้ำ น้ำของคลองนี้ออกทางไหน (อาจมีหลายทาง) |
| `operators` | รายการ | หน่วยงานควบคุม เช่น `กทม.-สำนักระบายน้ำ`, `การชลประทาน`, `การประปานครหลวง` |
| `confidence` | `high` \| `medium` \| `low` | ความเชื่อมั่นรวมของ "ทิศทางการไหล" (นิยามด้านล่าง) |
| `status` | `verified` \| `inferred` \| `conflicting` \| `not-found` | สถานะข้อความทิศทางการไหลหลัก |
| `needs_verification` | รายการ | รายการข้อเท็จจริงย่อยที่ยังไม่มีแหล่งยืนยัน |
| `last_verified` | วันที่ ISO | วันที่ตรวจแหล่งอ้างอิงล่าสุด |

## ค่า `flow_type` (กลไกการไหล)

| ค่า | นิยาม | ตัวอย่าง |
|---|---|---|
| `river-arm` | เป็นอดีตลำน้ำเจ้าพระยาเอง (คุ้งน้ำเก่า) — น้ำจริงจากแม่น้ำไหลเข้าออกสองทิศตามน้ำขึ้นน้ำลง ปริมาณมาก | บางกอกใหญ่, บางกอกน้อย, ชักพระ |
| `tidal-sliver` | คลองสั้นปากเปิดแม่น้ำ — น้ำไหลย้อนสองทิศตามน้ำขึ้น ไม่มีประตูควบคุมใหญ่ | ช่องนนทรี, สาทร, คูเมืองชั้นใน |
| `controlled-drainage` | คลองระบายน้ำสายหลัก — ทิศทางสุทธิถูกกำหนดด้วยประตูน้ำและสถานีสูบน้ำที่ปากคลอง ไม่ใช่ความชัน | แสนแสบ, ลาดพร้าว, พระโขนง, บางซื่อ |
| `supply` | คลองส่งน้ำ — ถูกออกแบบให้พาน้ำจากแหล่งต้นเข้าสู่เครือข่าย (ทิศออกแบบตายตัว แต่ปัจจุบันอาจใช้กลับทางได้ด้วยประตู) | ประปา, ทวีวัฒนา (เดิม), มหาสวัสดิ์, ระพีพัฒน์ |
| `stagnant-controlled` | น้ำแทบนิ่ง มีการหมุนเวียนด้วยการดำเนินการของ กทม. เป็นครั้งคราว | ผดุงกรุงเกษม, คูเมืองเดิม |
| `unknown` | ยังไม่มีข้อมูลเพียงพอ | — |

## ระดับ `confidence` (ใช้กับข้อความทิศทางการไหล)

- **high** — มีแหล่งอิสระ ≥ 2 หรือแหล่งชั้นต้น (หน่วยงานราชการ) ที่พูดถึงข้อเท็จจริงนั้นตรง ๆ
- **medium** — มีแหล่งเดียว หรืออนุมานจากโครงสร้าง/การดำเนินงานที่มีแหล่งรองรับชัดเจน (เช่น "สถานีสูบน้ำพระโขนงดึงน้ำจากคลองแม่น้ำ X" → อนุมาน X ระบายเข้าพระโขนง)
- **low** — อนุมานจากเรขาคณิต/ระบบเพียงอย่างเดียว หรือแหล่งขัดแย้งกัน หรือยังไม่พบแหล่งใด (`status: not-found` มักคู่กับ `low`)

## ป้ายในเนื้อหา

- **[verified]** — มีแหล่งอ้างอิง URL ตรงกับข้อความ
- **[inferred]** — อนุมาน พร้อมเหตุผลที่ให้อนุมานได้
- **[conflicting]** — แหล่งขัดแย้ง ระบุทั้งสองฝั่ง
- **[not-found / needs-verification]** — หาไม่พบ ห้ามเดา

## กติกาการแก้ไข

1. แก้เนื้อหา → ต้องแนบ URL แหล่งใหม่ท้ายข้อความ + อัปเดต `last_verified`
2. พบข้อขัดแย้ง → อย่าลบฝั่งเก่า ให้เพิ่มป้าย `conflicting` แล้วบันทึกทั้งสองข้อพร้อมเหตุผลที่เชื่อฝั่งใดมากกว่า
3. อย่ารวมคลองหลายสายเป็นไฟล์เดียวถ้าต่าง `flow_type` หรือต่างฝั่งแม่น้ำ
4. ชื่อคลองซ้ำข้ามจังหวัด (เช่น คลองด่าน 2 สาย, คลองบางขุนเทียน) — ระบุจังหวัด/เขตกำกับทุกครั้ง อย่าเขียนชื่อเปล่า
