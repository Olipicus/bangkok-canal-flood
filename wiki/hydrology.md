# อุทกวิทยาเครือข่ายคลองกรุงเทพฯ — อ่านไฟล์นี้ก่อนตีความทิศทางการไหล

> ข้อความสำคัญที่สุด: **คลองกรุงเทพฯ เกือบทั้งหมดไม่มีทิศทางการไหลตายตัว** ทิศทางในแต่ละช่วงเวลาถูกกำหนดด้วย (1) ระดับน้ำแม่น้ำเจ้าพระยากับน้ำขึ้นน้ำลง (2) การเปิด-ปิดประตูระบายน้ำ (3) การเดินเครื่องสูบน้ำ (4) ตำแหน่งฝน/แหล่งน้ำท่วม เอกสารฉบับนี้รวมกลไกทั้งสี่ตามแหล่งอ้างอิง

## 1. แม่น้ำเจ้าพระยาคือ "หัวปั๊ม" ของทั้งระบบ

- พื้นที่กรุงเทพฯ อยู่ต่ำ ระดับน้ำในแม่น้ำสูงกว่าพื้นเมืองเป็นช่วงใหญ่ของปี — คำพูดจากงานสำรวจปัญหาน้ำท่วม กทม.: "ยิ่งเป็นสถานีที่ต้องสูบน้ำลงเจ้าพระยา กำลังแรงของปั้มน้ำ...มีความจำเป็นมาก เพราะแม่น้ำเจ้าพระยาจะสูงกว่าพื้นที่กรุงเทพ" [ThaiPublica 2020, https://thaipublica.org/2020/10/flood-problems-in-bangkok02/] **[verified]**
- ผลที่ตามมา: คลองสายหลักทุกสายทำหน้าที่เป็น "อ่างกักน้ำที่มีประตู" มากกว่าเป็นลำธารที่ไหลเอง — น้ำระบายออกแม่น้ำได้ต้องอาศัย (ก) ช่วงน้ำลง/น้ำนอก (ข) ประตูเปิด (ค) ปั๊มช่วย **[verified — สังเคราะห์จากแหล่งเดียวกัน]**
- ปริมาณน้ำอ้างอิงของลุ่ม: เจ้าพระยาที่นครสวรรค์ ไหลเฉลี่ย ~718 m³/s สูงสุดบันทึกไว้ ~5,960 m³/s (สถานีอยู่เหนือกรุงเทพฯ) [en.wikipedia Chao Phraya River] **[verified]** และระบบระบายน้ำของกรุงเทพฯ (แม่น้ำ + สถานีสูบน้ำรอบเมือง) ระบายได้ "อย่างน้อย 420,000,000 ลูกบาศก์เมตรต่อวัน" ในสถานการณ์น้ำใหญ่ [มหาอุทกภัย พ.ศ. 2554, th.wikipedia] **[verified]**

## 2. น้ำขึ้นน้ำลง (Tide) — เหตุผลที่ทิศทางกลับได้สองครั้งต่อวัน

- การทำงานของระบบเป็นไปตามจังหวะน้ำทะเล: หลัก "แก้มลิง" ของในหลวง ร.9 สรุปเป็น "ขุดคลองชักน้ำมารวมกันเก็บเป็นบ่อพักน้ำ แล้วระบายลงทะเลเมื่อระดับน้ำทะเลลดลง" [th.wikipedia แก้มลิง] **[verified]** — นั่นคือ กทม. กักน้ำในคลองช่วงน้ำขึ้น แล้วเปิดประตู/เดินปั๊มระบายช่วงน้ำลง
- ช่วงน้ำทะเลหนุนสูงสุดของปี (ประมาณ ต.ค.–พ.ย.) เป็นช่วงวิกฤต: ข่าว ก.ย. 2569 ระบุ กทม. "เฝ้าระบายน้ำทะเลหนุน 10–11 ต.ค." [The Standard, https://thestandard.co/chatchart-bangkok-flood-plan-eastern-canals/] **[verified]**
- น้ำทะเลหนุนทำให้ปากคลองทุกปาก "ย้อนทิศ" — น้ำแม่น้ำดันเข้าคลอง การไหลในคลองชายเมือง (เช่น ช่องนนทรี, สาทร, คูเมือง, บางกอกใหญ่/น้อย) กลับทิศตามน้ำขึ้นน้ำลง — ระดับน้ำในคลองเมืองเก่าขึ้นลงตามแม่น้ำ (ดูรายการคลองท่าวาสุกรีในทำเนียบคลอง กทม. ที่ว่า "สภาพน้ำขึ้นอยู่กับระดับน้ำในแม่น้ำเจ้าพระยา") [รายชื่อคลองในกรุงเทพมหานคร, th.wikipedia] **[inferred→ขยายจากแหล่ง verified]**
- ยังไม่มีแหล่งในชุดนี้ที่ให้ตัวเลข "ระยะที่น้ำเค็มวิ่งขึ้นไป" หรือ "ช่วงน้ำขึ้นกี่ชั่วโมง" — `needs-verification` กับการชลประทาน/กรมอุทกศาสตร์

## 3. ระบบประตูน้ำและปั๊ม — ผู้ตัดสินทิศทางจริง

กำลังสูบน้ำฝั่งพระนคร (ตะวันออก): 743.62 m³/s (ต.ค. 2563) → "เร่งเดินเครื่องสูบน้ำฝั่งพระนครเต็มกำลังที่ 1,200 ลูกบาศก์เมตรต่อวินาที" (ก.ย. 2569) [ThaiPublica 2020; The Standard 25.09.2026] **[verified]**

ประตูน้ำและสถานีสูบน้ำที่มีแหล่งยืนยัน (ดูพิกัดใน `canals/index.md`):

| โครงสร้าง | คลอง/ตำแหน่ง | บทบาท |
|---|---|---|
| สถานีสูบน้ำพระโขนง (173 m³/s, ใหญ่สุดใน กทม.) | ปากคลองพระโขนงลงเจ้าพระยา | หัวปั๊มปลายทางของกรวยฝั่งตะวันออก รับน้ำจากแสนแสบ/ประเวศบุรีรมย์/อุโมงค์ราม 9 [ThaiPublica 2019; The Standard 2026] |
| ประตูระบายน้ำคลองลัดโพธิ์ (Lat Pho, 8 ประตู) | ปากคลองพระโขนง → เจ้าพระยา | ประตูปากคลองหลักฝั่งตะวันออก-ใต้ [OSM waterway=sluice_gate, 2026-09-27] |
| อุโมงค์ระบายน้ำราม 9 (~60 m³/s) | ตัดกับคลองลาดพร้าว → พระโขนง | "สะดือในการระบายน้ำของกรุงเทพฯ" [ThaiPublica 2019] |
| อุโมงค์บึงหนองบอน–บางอ้อ (~60 m³/s, 9.4 กม.) | หนองบอน/คลองเคล็ด/บางนา → เจ้าพระยา | ก.ย. 2569 เดินเครื่อง 4 จาก 6 ตัว = 40 m³/s [The Standard 2026] |
| ประตูระบายน้ำคลองสามวา | ปลายคลองสามวา มีนบุรี | จุดตัดสินชะตาปี 2554 (ดู §5) [มหาอุทกภัย 2554] |
| สถานีสูบน้ำบางซื่อ + อุโมงค์บางซื่อ (Ø5 ม., ~6.4 กม., ออกแบบ 60 m³/s) | คลองบางซื่อ → เจ้าพระยา | หัวระบายฝั่งเหนือ-ใน [th.wikipedia คลองบางซื่อ; ข่าว กทม. 2565] |
| ประตูน้ำฉิมพลี / ประตูน้ำมหาสวัสดิ์ (การชลประทาน) | ปลายตะวันออก/ตะวันตกของคลองมหาสวัสดิ์ | คุมเชื่อมเจ้าพระยา ↔ ท่าจีน [th.wikipedia คลองมหาสวัสดิ์ (ไม่มี ref ในหน้า) — medium] |
| ประตูน้ำภาษีเจริญตอนนอก/ตอนใน (สร้าง 2450–2452) | คลองภาษีเจริญ | คุมการแลกเปลี่ยนกับเจ้าพระยา/ท่าจีน [th.wikipedia คลองภาษีเจริญ (ไม่มี ref ที่ย่อหน้าประตู) — medium; en-wiki อ้างว่าออกแบบเนเธอร์แลนด์ ต่างจาก th-wiki → conflicting] |
| ประตูแก้มลิงคลองทวีวัฒนา (พิกัดโดยประมาณ 13.7830, 100.3765) | คลองทวีวัฒนา | กัก-ระบายน้ำฝั่งตะวันตก (โครงการแก้มลิงของ กทม.) — ชื่อ/พิกัดจากโน้ตโปรเจกต์ + ข่าว กทม. **ต้องยืนยันกับ กทม.** — medium |
| ประตูระบายน้ำสรรพาวุธ | แนวคลองบางซื่อ | จุดควบคุมบนเส้นบางซื่อ [OSM] |
| สถานีสูบน้ำดิบสำแล / บางซื่อ (การประปา) | เจ้าพระยา → คลองประปา | ส่งน้ำดิบลงใต้สู่สถานีผลิตน้ำ [th.wikipedia คลองประปา] |

- กทม. ใช้เครื่องผลักดันน้ำในคลองวิกฤต "เพื่อเร่งการไหลของน้ำ" (ก.ย. 2569) [The Standard 2026] **[verified]** — แสดงว่าแม้คลองระบายหลักก็ไหลช้าจนต้องเร่งด้วยเครื่องจักร
- หลักการตั้งชื่อให้จำ: **ประตูปากคลอง = กำแพงกันน้ำแม่น้ำ/น้ำทะเล, ปั๊ม = เครื่องยกน้ำออกเมื่อประตูปิดอยู่** — คลองใดมีทั้งสองอย่างที่ปาก ทิศทางการไหลของคลองนั้น "เป็นผลของตารางทำงาน" ไม่ใช่ภูมิประเทศ

## 4. ภาพใหญ่: กรวยระบายน้ำสองฝั่ง

**ฝั่งตะวันออก (พระนคร)** — พื้นที่รูปชามสูงทางตะวันออกเฉียงเหนือ (หนองจอก/ลาดกระบัง/มีนบุรี) น้ำไหลลงทางตะวันตกเฉียงใต้สู่เจ้าพระยา ผ่านกรวยซ้อนกัน 3 ชุด [สังเคราะห์จาก ThaiPublica 2019/2020 + The Standard 2026] **[verified ระดับโครงสร้าง]**:

1. กรวยแสนแสบ: คลองสามวา/หกวา (จากรังสิต-ลำลูกกา) → สามวา → **สองต้นนุ่น** → ประเวศบุรีรมย์/แสนแสบ → พระโขนง/อุโมงค์ราม 9 → ปั๊มพระโขนง
2. กรวยลาดพร้าว: บางบัว/คลองถนน → **ลาดพร้าว** → แสนแสบ → อุโมงค์ราม 9 → พระโขนง
3. กรวยบางนา: บางนา/สุขุมวิท 101/1/หนองบอน/เคล็ด → อุโมงค์หนองบอน → **บางอ้อ** → เจ้าพระยา

ข้อความตรงจากผู้ว่าฯ (ก.ย. 2569): "ทั้งคลองแสนแสบ คลองพระองค์เจ้าไชยานุชิต และคลองประเวศบุรีรมย์...จะต้องถูกดึงมารวมที่สถานีสูบน้ำพระโขนงเพื่อระบายออกต่อไป" และ "ใช้อุโมงค์ระบายน้ำบึงหนองบอน เป็นตัวช่วยดึงมวลน้ำจากโซนสุขุมวิท-บางนา มาลงที่สถานีสูบน้ำบางอ้อ" [The Standard 25.09.2026] **[verified]**

**ฝั่งตะวันตก (ธนบุรี)** — โครงสร้างสองชั้น:

1. แขนน้ำเก่าของเจ้าพระยา: บางกอกใหญ่ + บางกอกน้อย + ชักพระ (เดิมเป็นลำน้ำหลักก่อนริมฝีปากแม่น้ำตัดคลองลัด "คลองลัดบางกอก" สมัยสมเด็จพระไชยราชาธิราช พ.ศ. 2077–2089 [th.wikipedia บางกอกใหญ่/บางกอกน้อย/ชักพระ] **[verified ยกเว้นปีที่แน่นอน — conflicting: ตำราบางแหล่งเขียน พ.ศ. 2065]**) — น้ำในแขนเหล่านี้คือน้ำแม่น้ำจริง ไหลสองทิศตามน้ำขึ้นน้ำลง
2. คลองลัดตัดข้ามไปแม่น้ำท่าจีน (สายระบาย/ส่งน้ำทางประวัติศาสตร์): ภาษีเจริญ (เปิด พ.ศ. 2415) → ท่าจีนที่กระทุ่มแบน; ทวีวัฒนา (พ.ศ. 2421) → ท่าจีนที่บางเลน — สุนทรพจน์หลวงระบุทิศทางออกแบบชัด: "เพื่อชักน้ำจากแม่น้ำท่าจีนให้ไหลลงทิศใต้" [th.wikipedia คลองทวีวัฒนา] **[verified]**; สายคลองด่าน–สนามชัย (อยุธยา) → ท่าจีนที่มหาชัย [th.wikipedia คลองสนามชัย] **[verified]**; มหาสวัสดิ์ (พ.ศ. 2402–2403) → ท่าจีนที่นครชัยศรี [th.wikipedia] **[verified]**

ปลายทางของน้ำกรุงเทพฯ จึงมี **3 ทะเล/แม่น้ำรับ**: เจ้าพระยา (ทางปั๊มหลัก), ท่าจีน (ฝั่งตะวันตก), บางปะกง (ฝั่งตะวันออก — ผ่านแสนแสบตอนปลาย/คลองบางขนาก, ประเวศบุรีรมย์ตอนปลาย ออกที่ฉะเชิงเทรา) — โน้ตการชลประทานว่าจังหวัดเพื่อนบ้าน "สูบน้ำออกเพื่อบรรเทาผลกระทบเพียงบางส่วน" เพราะกังวลน้ำที่ผลักไปกระทบพื้นที่เกษตร [The Standard 2026] **[verified]**

## 5. กรณีศึกษาทิศทาง: มหาอุทกภัย พ.ศ. 2554

- น้ำเหนือไหลลงตามแม่น้ำ "อุทกภัยมักเริ่มขึ้นในภาคเหนือแล้วค่อยขยายวงลงมาตามแม่น้ำเจ้าพระยา" [มหาอุทกภัย 2554, หัวข้อสาเหตุ] **[verified]**; ลุ่มรังสิตท่วมก่อน (ตลาดรังสิต 22 ต.ค.) — แปลว่าประตูแนวเหนือ (รังสิต-หกวา-สามวา-เปรมประชากร) คือแนวที่น้ำเหนือ "พยายามไหลเข้าเมือง" **[inferred จากลำดับเหตุการณ์]**
- ยุทธการประตูคลองสามวา (ข้อพิพาททิศทางที่บันทึกชัดที่สุดในประวัติศาสตร์ร่วมสมัย):
  - 31 ต.ค. 2554: "ยิ่งลักษณ์ ชินวัตรมีคำสั่งให้กรุงเทพมหานครเปิดประตูระบายน้ำคลองสามวา 1 เมตร" — รัฐบาลต้องการระบายน้ำเหนือ **ออกทางตะวันออก** ผ่านคลองสามวา; กทม. ต้องการเปิดเพียง 75–80 ซม. เพื่อป้องกันนิคมบางชัน; ชาวบ้านบางฝ่ายขอ 1.5 เมตร
  - 1 พ.ย. 2554: ชาวสองฝั่งปะทะกัน — คนฝั่งต้นน้ำ (คลองสามวา/มีนบุรี) อยากให้น้ำออกผ่านประตู, คนฝั่งปลายน้ำ (มีนบุรี) ไม่รับน้ำเข้า [มหาอุทกภัย 2554, refs 49–53] **[verified]**
  - 7 พ.ย. 2554: กทม. ประกาศเขตคลองสามวาเป็นเขตอพยพ (รวม 12 เขต) [ref 54] **[verified]**
- การป้องกันเมือง: "ทางสำนักงานเขตได้เตรียมกระสอบทรายห้าแสนใบ" (8 ต.ค. 2554) และ กทม. ระบายผ่าน "ประตูระบายน้ำ 3 แห่ง" [refs 36, 44] **[verified]** — คลองประปา/วิภาวดี (Big Bag กันน้ำเข้าสถานีสูบน้ำดิบ) และแนวกระสอบทรายแสนแสบพบในข่าวชั่วโมงนั้น แต่ยังไม่มีในแหล่งที่ตรวจแล้วของชุดนี้ → `needs-verification`
- ผลสุทธิ: น้ำปริมาณ ~16,000 ล้าน m³ ระบายลงทะเลใช้เวลา "30 ถึง 45 วัน" หลังฝนหยุด [ref 44] **[verified]** — ความจุระบายของเครือข่ายคือคอขวดจริงของเมือง

| พ.ค.–ก.ค. (ต้นฤดูฝน) | ฝนฉับพลันท้องถิ่น | น้ำฝน → คลองซอย → คลองหลัก → ปั๊มลงแม่น้ำช่วงน้ำลง; ทิศ "หลังบ้านสู่แม่น้ำ" |
| ส.ค.–ต.ค. (น้ำหลากเหนือ) | ปล่อยน้ำเขื่อน + น้ำเหนือลงลุ่ม | ประตูแนวเหนือ/ตะวันออกปิดหรือควบคุม — คลองเหนือ (เปรมประชากร, แสนแสบตอนนอก, สามวา) รับแรงกดจากเหนือ; แก้มลิงกัก-ปล่อยตามจังหวะ |
| ต.ค.–พ.ย. (น้ำทะเลหนุนสูงสุดปี) | น้ำขึ้นสูง + น้ำเหนือยังมา | ปากคลองเกือบทุกปากปิด น้ำในเมืองไหลช้า/ย้อนทิศช่วงน้ำขึ้น — ขึ้นกับปั๊มล้วน ๆ |
| ธ.ค.–เม.ย. (ฤดูแล้ง) | น้ำแม่น้ำต่ำ, เค็มวิ่งขึ้น | ประตูบางจุดเปิดรับน้ำแม่น้ำเข้าคลองเพื่อชลประทาน/กดน้ำเค็ม/หมุนเวียนคุณภาพน้ำ (เช่น คูเมืองเดิม "ผันน้ำจากแม่น้ำเจ้าพระยาเข้าคลอง" ตามโครงการฟื้นฟู 2561) [th.wikipedia คลองคูเมืองเดิม] **[verified]** |

## 7. วิธีกำหนด "ทิศทางการไหล" ให้คลองหนึ่ง ๆ (แนวปฏิบัติสำหรับ AI Agent)

1. หา **ปากคลอง/จุดออกแม่น้ำ** ก่อน — มีประตูหรือปั๊มหรือไม่ ชื่ออะไร
2. ถามว่าคลองอยู่ในกรวยไหน (ฝั่งตะวันออก = ไหลหาหัวปั๊ม; แขนน้ำเก่าฝั่งตะวันตก = สองทิศตามน้ำขึ้น; คลองส่งน้ำ = ทิศออกแบบตามประวัติ)
3. เขียนทิศทางแบบมีเงื่อนไข: "ระบาย: X → Y", "น้ำขึ้น: ย้อน Y → X", "ฤดูแล้ง: รับน้ำจาก Z" — **ห้ามเขียนทิศเดียวแบบเด็ดขาด**
4. ตรวจว่าการไล่เส้นทางระบาย (trace ในแผนที่) ผ่านจุดประตู/ปั๊มจริงหรือไม่ — ถ้า trace ทะลุประตูที่ปกติปิด ให้แจ้งเตือนใน UI หรือปรับกราฟ
