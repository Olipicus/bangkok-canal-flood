# วิกิคลองกรุงเทพฯ (Bangkok Canal Wiki) — สำหรับ AI Agent

ฐานความรู้เรื่องคลองในกรุงเทพมหานครและเครือข่ายคลองโดยรอบ เขียนให้ **AI Agent อ่านและใช้ปรับปรุงข้อมูลของโปรเจกต์** (แผนที่สถานการณ์น้ำท่วม, ไฟล์ `build_data.mjs` → `CURATED`, ระบบไล่เส้นทางระบายน้ำ) ให้ถูกต้องและเชื่อถือได้มากที่สุด

จุดเน้นหลักตามที่ผู้ใช้กำหนด: **ทิศทางการไหลของแต่ละคลอง** — ซึ่งในกรุงเทพฯ "ทิศทางการไหล" ไม่ใช่ค่าตายตัว แต่เป็นผลของ (1) น้ำขึ้น-น้ำลงทะเล (2) ประตูระบายน้ำ (3) สถานีสูบน้ำ (4) ฤดูกาล ทุกไฟล์คลองจึงแยกให้ครบทั้ง 4 ชั้น พร้อมระบุว่าข้อไหน "มีแหล่งอ้างอิง" และข้อไหน "อนุมาน"

## กติกาการใช้งานสำหรับ AI Agent

1. **อ่าน `hydrology.md` ก่อน** — ทิศทางการไหลของคลองกรุงเทพฯ ต้องตีความร่วมกับน้ำขึ้นน้ำลงและการทำงานของประตู/ปั๊ม อ่านคลองเดี่ยวโดยไม่อ่านบริบท = เข้าใจผิดแน่นอน
2. **เคารพคอลัมน์ความเชื่อมั่น** — ห้ามยกระดับ `inferred` เป็น `verified` โดยไม่มีแหล่งใหม่; ห้ามนำข้อมูลจากไฟล์ที่ `confidence: low` ไปเขียนทับข้อมูลที่ตรวจสอบแล้ว
3. **ทุกข้อเท็จจริงต้องมาพร้อมแหล่งอ้างอิง (URL)** — เวลาแก้ไขไฟล์นี้ ให้ใส่แหล่งต่อท้ายข้อความที่แก้ทุกครั้ง ถ้าหาแหล่งไม่ได้ ให้เขียนกำกับว่า `not-found` และ `needs-verification` อย่าแต่งเติม
4. **อัปเดตเมื่อข้อมูลเปลี่ยน** — กำลังปั๊ม กติกาเปิดประตู และโครงการอุโมงค์เปลี่ยนบ่อย (ดูเหตุการณ์ ก.ย. 2569 ใน `hydrology.md`) เมื่อพบข้อมูลใหม่ ให้แก้ไฟล์คลองนั้น + ปรับ `last_verified` ใน frontmatter เป็นวันที่ตรวจ
5. **เชื่อมโยงกลับโปรเจกต์** — ถ้าใช้ข้อมูลจากวิกิไปแก้ `CURATED` ใน `build_data.mjs` ให้เพิ่มรายการใน `map-corrections.md` ด้วย (ระบุวันที่และสิ่งที่เปลี่ยน) เพื่อไม่ให้สองแหล่งคลาดกัน

## ขอบเขตและข้อจำกัดของข้อมูล (อ่านก่อนใช้)

- วันที่รวบรวมล่าสุด: **2026-09-27** จากวิกิพีเดียไทย/อังกฤษ, สำนักการระบายน้ำ กทม. (ไฟล์เก็บถาวร), ThaiPublica, The Standard, ข่าวการชลประทาน, และข้อมูล OpenStreetMap (Overpass, 2026-09-27)
- เว็บไซต์ การชลประทาน (rid.go.th) และ สำนักระบายน้ำ กทม. แบบสด เข้าไม่ได้ในคราวรวบรวม — ข้อมูลฝั่งชลประทาน (ระพีพัฒน์, มหาสวัสดิ์ ฯลฯ) จึงส่วนใหญ่มาจากแหล่งรอง ควรตรวจซ้ำกับ RID โดยตรงเมื่อทำได้
- **พิกัดทั้งหมดเป็นค่าประมาณจาก OSM (คลาดเคลื่อน ~50–200 ม.)** ไม่ใช่ค่าสำรวจ — ใช้ไขว้ตำแหน่งหยาบ ๆ ได้ ห้ามใช้เป็นพิกัดงานวิศวกรรม
- สถิติแบบ "จำนวนคลอง/ความยาวรวม" มีหลายชุดไม่ขัดกันแต่ต่างขอบเขต: BMA สำรวจปี 2553 พบ 1,161 คลอง + 521 คูลำระบาย = 2,604 กม. (เฉพาะ กทม.); แผนที่ของโปรเจกต์นี้นับ 1,454 คลอง / 6,146 กม. เพราะรวมเครือข่ายจังหวัดโดยรอบจาก OSM — อย่านำมาชี้ว่าใครผิด

## สรุปหนึ่งบรรทัดสำหรับ Agent ที่รีบ

คลองกรุงเทพฯ ไม่มี "ทิศทางการไหลประจำตัว" แบบธรรมชาติ — ฝั่งตะวันออกเป็นกรวยระบายน้ำหลายชั้นที่หัวปั๊มอยู่ที่แม่น้ำ (พระโขนง 173 m³/s, อุโมงค์ราม 9 และหนองบอน 60 m³/s ฯลฯ) ฝั่งธนบุรีเป็นคุ้งแม่น้ำเก่า + คลองลัดสู่แม่น้ำท่าจีนที่ไหลสองทางตามน้ำขึ้นน้ำลง — และทุกปากคลองสู่แม่น้ำมีประตูน้ำเป็นผู้ตัดสินว่าน้ำจะออกหรือเข้า
