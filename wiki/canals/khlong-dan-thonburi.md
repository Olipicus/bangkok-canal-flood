# คลองด่าน (ฝั่งธนบุรี) (Khlong Dan, Thonburi)

## สรุปทิศทางการไหล (หนึ่งบรรทัด)
หัวหอกใต้ของเครือข่ายบางกอกใหญ่: บางกอกใหญ่ → ด่าน → สนามชัย → **แม่น้ำท่าจีนที่มหาชัย** — สายลัดข้ามคาบสมุทรของน้ำฝั่งธนบุรีใต้; ทิศสุทธิตามระดับน้ำเจ้าพระยา-ท่าจีน และประตูปลายสาย (สมุทรสาคร) **[verified เส้นทาง / inferred ทิศ]**

## เส้นทางและจุดเชื่อมต่อ
- "ปากคลองแยกจากคลองบางกอกใหญ่ที่วัดปากน้ำภาษีเจริญ ไปออกคลองบางขุนเทียน และคลองสนามชัย" [th.wikipedia, ref สำนักการระบายน้ำ กทม.] **[verified]**
- ท้องถิ่น: "จะถือกันว่าคลองสนามชัยและคลองด่านเป็นคลองเดียวกัน" [th.wikipedia สนามชัย] **[verified]**
- **ระวังตอนจับคู่ชื่อในแผนที่**: มี "คลองด่าน" อีกสายในสมุทรปราการ (แถบบางปลากด) — คนละคลองกับด่านฝั่งธนบุรี **[verified]**

## ทิศทางตามสถานการณ์
- ปกติ: น้ำขึ้น-ลงตามแม่น้ำสองฝั่ง; ระบายฝนย่านจอมทอง/ภาษีเจริญใต้ ออกท่าจีน **[inferred]**
