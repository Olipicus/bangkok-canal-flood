# แบ่งคลองยาวเป็นหลายช่วงตามจุดวัด พร้อมสีสถานะรายช่วง

## ทำได้แน่นอน และข้อมูลรองรับอยู่แล้ว
- คลองแสนแสบมี **12 สถานีวัด** กระจายทั้งแนว (โบ๊เบ๊ → อโศก → เจ้าคุณสิงห์ → เสรีไทย 24 → หนองจอก) แต่ละสถานีมีสถานะ/ระดับน้ำ/พิกัดของตัวเองใน `data/live_status.js` — ตอนนี้ถูก "ยุบ" เป็นสถานะเดียวของทั้งคลอง (แย่สุดชนะ) ทำให้แสนแสบแดงทั้งสายทั้งที่บางช่วงปกติ
- มีคลอง ≥2 สถานีราว 30 สาย (แสนแสบ 12, สามเสน 9, เปรมประชากร 8, ประเวศบุรีรมย์ 6, ภาษีเจริญ 5 ฯลฯ)

## จุดที่ทำให้เรื่อง "ชื่อซ้ำ" ปลอดภัย (ไม่ต้องกลัวปนกัน)
- การแบ่งช่วงทำงานบน **`key` ของฟีเจอร์** (unique) ไม่ใช่ชื่อ — คลองชื่อซ้ำถูกแยกเป็นฟีเจอร์ล่วงหน้าแล้วตั้งแต่ build (`Khlong Dan` กับ `Khlong Dan #2` เป็นคนละ key)
- สถานีถูก attach เข้า key ที่ถูกต้องตั้งแต่ `fetch_live.mjs` (จับคู่ชื่อโดยเลือก component ที่อยู่ใกล้สถานีที่สุด / หรือ within 200 ม.) — เราใช้เฉพาะสถานีที่ `station.canal === key` เท่านั้น จึงไม่มีทางสถานีของคลองสายอื่น (แม้ชื่อเดียวกัน) หลุดเข้าช่วงของคลองนี้
- **ไม่แก้ pipeline ข้อมูลเลย** — แก้เฉพาะ frontend (`app.js`, `style.css`) ไม่กระทบสคริปต์ refresh snapshot ที่รันตาม cron

## การคำนวณช่วง (ใหม่ใน app.js)
1. เย็บเส้น MultiLineString ของคลองเป็น chain เรียงต่อเนื่องเส้นเดียว (ต่อปลายเข้าหาปลาย, tolerance ~1e-4°) เทคนิคเดียวกับ `riverPathDown` ที่มีอยู่ → ได้ระยะสะสม (กม.) ตลอดแนว
2. Project พิกัดสถานีลงบน chain (segment projection แบบ `nearestOnCanal` บรรทัด 597–614) → ตำแหน่ง กม. ของแต่ละสถานี
3. เรียงสถานีตามตำแหน่ง; สถานีที่ห่างกัน <300 ม. รวมเป็นช่วงเดียว (สถานะ = แย่สุด)
4. เส้นแบ่งช่วง = จุดกึ่งกลางระหว่างช่วงข้างเคียง — ช่วงแรก/สุดท้ายยืดถึงปลายคลอง (ใช้สถานะสถานีใกล้สุด)
5. ตัดเรขาคณิตเป็นท่อน ๆ ด้วย slice helper ใหม่ตามช่วงระยะ
6. สถานี **ขัดข้อง** (เช่น WL.SSB.02 ซอยสมคิด) → ช่วงสีเทา `#9e9e9e` + ป้าย "ขัดข้อง"
7. Fallback กลับวิธีเดิม (ทั้งสายสีเดียว) เมื่อ: <2 สถานี, chain เย็บต่อไม่ได้ (เส้นไม่ต่อเนื่องกันจริง ๆ)
- คำนวณครั้งเดียวตอนโหลดหน้า (คลอง ~30 สาย, เร็วมาก) เก็บ cache ต่อ key

## การแสดงผล (เฉพาะตอนเลือกคลอง — หน้าปกติคงเดิม)
- `drawTrace`: คลองที่เลือกถ้ามีหลายช่วง → วาดเป็น polyline รายช่วง (casing ขาว + สีสถานะรายช่วง + เส้นประไหลทิศเหมือนเดิม) + **จุดสถานี** circleMarker สีตามสถานะ, tooltip ชื่อ+ระดับน้ำ (`bubblingMouseEvents:false` กัน Esc-clear ตอนคลิกจุด)
- แผงรายละเอียด: แทนรายชื่อสถานีเดิมด้วยบล็อก **"ช่วงตามจุดวัด (N ช่วง)"** — แต่ละแถว: จุดสี, ช่วง กม., ชื่อสถานี (ช่วง...), ระดับน้ำ, สถานะ → คลิกแถว = ซูมเข้าช่วงนั้น + flash เส้น / คลิกจุดบนแผนที่ = ไฮไลต์แถวเดียวกัน
- หัวบล็อกยังสรุปสถานะแย่สุด + เกณฑ์เหมือนเดิม

## แจ้งเตือนชื่อซ้ำในรายการค้นหา
- ค้นหาชื่อซ้ำหลายสาย (เช่น "คลองด่าน") ตอนนี้แถวเหมือนกันหมด → เติม hint ที่ปลายแถว: **เขต** จากสถานีใกล้สุด (≤2 กม.) หรือ "ต่างจังหวัด" ถ้านอกกรุงเทพฯ

## โบนัสที่มาจากข้อมูลเดียวกัน
- สถิติ "กม. วิกฤตขณะนี้" คิดรายช่วงสำหรับคลองหลายสถานี (แม่นยำขึ้น — แสนแสบไม่นับแดงทั้ง 52 กม. อีกต่อไป)

## i18n + CSS
- เพิ่ม string ไทย/อังกฤษ (หัวข้อบล็อกช่วง, ป้าย กม., ขัดข้อง ฯลฯ) รองรับสลับภาษาขณะแผงเปิดอยู่
- `style.css`: รายการช่วง, จุดสถานี, flash highlight

## ทดสอบ (เปิดเซิร์ฟเวอร์ + เช็คผ่านเบราว์เซอร์)
1. คลิก/ค้นหาคลองแสนแสบ → เห็นหลายช่วงหลายสี + จุดสถานี + รายการช่วงในแผง, คลิกแถวช่วง → ซูมถูกจุด, Esc → กลับสู่หน้าปกติ
2. คลองชื่อซ้ำ: ค้น "คลองด่าน" เลือกทีละสาย → ช่วง/สถานีไม่ปนกัน, hint เขตถูกต้อง
3. คลองสถานีเดียว → คงพฤติกรรมเดิม, คลองไม่มีสถานี → เทาเหมือนเดิม
4. สลับ TH/EN ขณะเลือกอยู่ → แผง re-render ครบ

**ไฟล์ที่แตะ:** `app.js` (+~200 บรรทัด), `style.css` (+~50 บรรทัด) — ไม่แตะ `data/*`, `fetch_live.mjs`, `build_data.mjs`
